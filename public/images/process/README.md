# 검증 프로세스 현장 사진 교체 가이드

홈 페이지의 **검증 프로세스 4단계** 카드 상단에 들어가는 실제 현장 사진 위치입니다.

## 교체 규칙

| 파일명 | 단계 | 내용 |
|---|---|---|
| `step-1-site-visit.jpg` | 01 현장 방문 | 담당자가 매체 앞에서 점검하는 사진 |
| `step-2-measurement.jpg` | 02 촬영 및 실측 | 카메라/줄자/조도계 등 측정 장면 |
| `step-3-data-review.jpg` | 03 데이터 검증 | 모니터/리포트를 보며 데이터를 분석하는 장면 |
| `step-4-registration.jpg` | 04 매체 등록 | 플랫폼 등록 완료 — 확정 매체 전경 |

## 스펙

- 포맷: `.jpg` 또는 `.webp` (webp 권장)
- 비율: **16:9** (가로 1600 × 세로 900 권장)
- 용량: 각 장 **< 400KB** (Next/Image 가 webp/avif 로 재변환)
- 밝기: 네이비 오버레이 위에서도 식별되도록 **중간 밝기 이상**
