## 📍 슬라이드 2 — 왜 지금 전환해야 하는가 (1분 30초)

### 시장은 우리를 기다려주지 않습니다

**OOH 시장 3대 변화 (2026 현재)**

- 📉 **전통 대행사 점유율 하락**: 광고주가 셀프서비스 마켓플레이스 선호 증가
- 🚀 **HOO의 빠른 성장**: 마켓플레이스 모델로 ~20,000 매체 등록, 셀프 단일 채널
- 📊 **공공 데이터 개방 가속**: 유동인구·POI·교통 데이터로 OOH "근거 광고" 가능해짐

**THINKAD가 가진 시간 한정 기회**

| 기회 | 의미 |
|---|---|
| ✅ HOO는 **검증·풀서비스 부재** | 우리가 선점할 빈 사분면 (High Tech × High Touch) |
| ✅ 14년 **현장 검증 조직** = 물리적 자산 | HOO가 자본으로 살 수 없는 자산 |
| ✅ 백엔드(Prisma 16모델·Admin·PDF) **이미 70% 준비됨** | 프런트·UX만 13주 집중하면 베타 가능 |
| ⏰ 6개월 후엔? | HOO가 검증 흉내내기 시작 → 차별화 약화 |

**🎯 핵심 메시지**
> "지금이 검증을 디지털 무기로 전환할 마지막 6~12개월 윈도우입니다."

**🎙 발표자 노트 (1분 30초)**
- "HOO는 매체 양으로 우리를 압박하지만, 검증·전문 상담은 못 하고 있습니다. 이게 우리의 6개월 선점 기회입니다."
- "백엔드 70%가 이미 준비됐다는 건, 13주 안에 베타가 가능하다는 것의 가장 강력한 근거입니다."

## 📍 슬라이드 3 — 우리의 차별화 무기 4가지 (2분)

### "신뢰는 THINKAD, 편의성은 HOO 이상"

```
┌─────────────────────────┬─────────────────────────┐
│ ① 4단계 현장 검증 + 배지 │ ② 3-Tier 서비스         │
│                         │                         │
│ 입지·가시성·조도·경쟁    │ Self    : 무료, 자동    │
│                         │ Assisted: +전문가 검수  │
│ → 매체 카드·PDF·필터    │ Full    : 전담 PM      │
│   모든 곳에 상시 노출    │                         │
│                         │ → Self → Full 전환 퍼널 │
├─────────────────────────┼─────────────────────────┤
│ ③ AI 플래너 + 자동 제안서│ ④ 양면 시장 네트워크    │
│                         │                         │
│ Claude tool use로       │ 매체사 포털 (Phase 3)   │
│ 30분 내 PDF 생성         │ + 대행사 White-label    │
│                         │                         │
│ → 출처 100% 표기 강제   │ → 양쪽 lock-in으로     │
│   환각 방지 검증 레이어  │   HOO 따라오기 어려움   │
└─────────────────────────┴─────────────────────────┘
```

**HOO와의 결정적 차이**

| 축 | HOO | THINKAD |
|---|---|---|
| 매체 검증 | 등록 심사만 | **현장 4단계 배지** |
| 제안서 | 24~48시간 수동 | **30분 자동 + 2시간 검수** |
| 데이터 | 매체사 자료 | **공공 + 자체 + 출처 표기** |
| 서비스 | 셀프 단일 | **Self / Assisted / Full** |

**🎯 핵심 메시지**
> "4가지 무기가 합쳐져야 'HOO가 못 따라오는 해자'가 됩니다. 하나라도 빠지면 그냥 또 하나의 마켓플레이스입니다."

**🎙 발표자 노트 (2분)**
- "이 4가지는 따로 보면 평범하지만, 합치면 HOO가 절대 단기간에 복제할 수 없는 구조가 됩니다."
- "특히 ① 4단계 검증은 매체본부의 14년 자산이 그대로 무기가 됩니다 — 자본으로 살 수 없는 것."
- "③ AI는 환각 방지가 핵심입니다. 가격을 LLM이 직접 답하지 못하게 하고, 모두 DB 쿼리 결과만 가공하게 설계합니다."
