## THINKAD가 대행사 AE에게 제공하는 것

### ① 30분 자동 제안서 PDF — 본부 대기 0분

장바구니에 매체 3~5개 담고 → 캠페인 정보 입력 → **1클릭 PDF**.
{{대행사명}} 로고·브랜드 컬러가 박힌 **White-label PDF**가 45~60초 내 다운로드됩니다.

클라이언트는 "벌써 받으셨어요?" 하고 놀랍니다. 차별화는 여기서 시작됩니다.

### ② THINKAD 4단계 현장 검증 배지 — 남들이 못 붙이는 것

입지·가시성·조도·경쟁매체. 제안서에 🛡️ 배지가 박혀 있으면 CMO 승인이 빠릅니다.
경쟁 대행사가 같은 매체를 제안해도, 배지 없는 PDF는 설득력이 다릅니다.

### ③ AI 매체플래너 — 30분 감으로 못 짜던 조합을 10초에

"강남 뷰티 타겟, 3천만원" 입력만 하면 Claude AI가 3안 제시:
- Conservative: 안정 리치 극대화
- Balanced: 인지도 + 전환 균형
- Aggressive: 단기 임팩트

각 안의 근거(유동인구·출처·CPM)까지 딸려옵니다. 그대로 클라이언트 설득 자료.

### ④ 매체 비교 툴 — `/compare`

최대 3개 매체 나란히 놓고 CPM·리치·검증 배지·가격이력 비교. 한 장 PDF 출력.
"왜 이 매체인가"를 증명하는 데이터가 전부 거기 있습니다.

### ⑤ 캠페인 진행·성과 자동 추적 — My THINKAD
