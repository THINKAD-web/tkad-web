## §1. 가격 단위 정책

### 현행 (이행기)

DB `Media.price` 컬럼은 **단위가 매체별로 혼재**한다. 운영팀 입력 관행에 따라:

- 큰 값(>= ₩1,000,000): 원(KRW) 단위.
- 작은 값(< ₩1,000,000): 만원 단위.

`lib/pricing/unit.ts:priceToWon(value, "auto")` 가 이 휴리스틱을 격리해 단일 함수로
처리한다. 다른 모든 코드는 이 함수를 통해 원 단위로 일원화한 뒤 계산한다.

### 마이그레이션 계획 (별도 후속 PR)

1. 운영팀과 단위 일원화 결정 (권장: 원).
2. `prisma/sql/2026_NN_media_price_unit.sql` 작성:
   - `UPDATE media SET price = price * 10000 WHERE price < 1000000`
   - `priceOptions` JSON 도 동일 규칙으로 일괄 변환.
3. Neon SQL editor 에서 사용자가 직접 실행.
4. `lib/pricing/unit.ts` 의 `auto` 분기 제거 → `won` 강제.
5. 어드민 가격 입력 폼에 단위 명시 (placeholder: "원").

### 예외

- 네트워크 매체(`MediaNetwork.pricePerUnit`, `pricePackage`)는 위 규칙과 동일 휴리스틱 적용.
- `priceOptions[i]` 도 동일 규칙. 각 옵션이 자체 `period` 를 가질 수 있으므로 `pricePeriod` 별 환산 시 이를 우선한다.

## §2. 할인 정책

코드 위치: `lib/pricing/discount-policy.ts`. 정책 변경은 본 파일 상수만 수정.

### 적용 방식

**큰 쪽만 한 개 적용**(중첩 X). 동률이면 기간 할인 우선 노출.

### 기간 할인 (`DURATION_TIERS`)

| 캠페인 일수 | 할인율 | 라벨 |
|---|---|---|
| 30 ~ 89일 | 5% | 30일 이상 장기 할인 |
| 90 ~ 179일 | 10% | 90일 이상 장기 할인 |
| 180일 이상 | 15% | 180일 이상 장기 할인 |

### 다중 매체 할인 (`MULTI_MEDIA_TIER`)

| 매체 수 | 할인율 | 라벨 |
|---|---|---|
| 5개 이상 | 3% | 5개 매체 이상 다중 할인 |

### 운영팀 확정 필요

- [ ] 위 수치 운영팀 최종 승인 (현재는 의뢰서 제안값).
- [ ] 신규 거래처 / 재거래처 추가 우대 도입 여부.
- [ ] 카테고리(디지털/옥외/모바일) 별 차등 도입 여부.

## §4. 부가세

- 한국 부가가치세 10% 별도(`VAT_RATE = 0.1`).
- 견적서/PDF 표기: 공급가, 부가세, 합계 모두 별도 노출.
- 어드민 견적은 `vatIncluded` 토글 지원(역산); 공개 견적은 항상 별도.

---

## §5. 라운딩

- 일 단가는 라인 단위에서만 round 적용 (`Math.round`).
- 라인 합계 → 할인 → VAT 순으로 round.
- 누적 오차 최소화를 위해 중간 계산은 부동소수 유지.
