## 싱커드 배포 체크리스트

배포 전/후로 아래 항목을 순서대로 점검하세요. 서비스 특성에 따라 필요 없는 항목은 표시하고, 추가로 필요한 항목은 확장해서 사용하면 됩니다.

---

## 1. 환경 변수 / 설정

- **기본 정보**
  - [ ] `NODE_ENV=production`
  - [ ] `NEXT_PUBLIC_` prefix가 필요한 클라이언트용 환경변수 정리 완료
  - [ ] `.env.production` 혹은 배포 환경 설정이 인프라에 올바르게 주입됨 (Vercel / Docker / k8s 등)

- **인증 / 보안**
  - [ ] `JWT_SECRET` 또는 세션 암호키 설정
  - [ ] OAuth / SSO 클라이언트 ID, Secret (예: Google, Kakao 등)
  - [ ] 관리자 계정 초기 비밀번호 및 접근 정책 점검

- **외부 API / 서드파티 서비스**
  - [ ] API Base URL (백엔드 / BFF) 설정
  - [ ] 모니터링 / 로깅 툴 키 (예: Sentry, Datadog 등)
  - [ ] 분석 툴 키 (예: GA, Amplitude 등)
  - [ ] 이메일 / SMS 발송 서비스 키

- **기타**
  - [ ] 파일 스토리지(S3 등) 관련 키 및 버킷 이름
  - [ ] 캐시/세션 스토어(Redis 등) 주소 및 비밀번호

---

## 2. 데이터베이스 / 마이그레이션

- **접속 정보**
  - [ ] DB 호스트, 포트, 사용자, 비밀번호, DB 이름 확인
  - [ ] 읽기/쓰기 분리 환경인 경우, 각각의 연결 정보 확인

- **마이그레이션**
  - [ ] 최신 스키마 마이그레이션 스크립트 작성 완료
  - [ ] 스테이징/테스트 환경에서 마이그레이션 리허설 완료
  - [ ] 롤백 스크립트 또는 롤백 전략 마련

- **데이터 품질**
  - [ ] 핵심 테이블(유저, 프로젝트, 거래 등) 데이터 정합성 점검
  - [ ] 인덱스/쿼리 성능 이슈 사전 점검

---

## 3. 도메인 / DNS

- **도메인 설정**
  - [ ] 서비스 메인 도메인 (예: `app.sinkerd.com`) 확정
  - [ ] 운영/스테이징/테스트 도메인 구분

- **DNS 레코드**
  - [ ] A / CNAME 레코드가 올바른 인프라 엔드포인트를 가리키는지 확인
  - [ ] 서브도메인(`api.`, `admin.` 등) DNS 설정 완료
  - [ ] TTL 값이 배포 전략에 맞는지 확인 (긴급 롤백 고려)

- **기타**
  - [ ] 도메인 만료일, 자동 연장 여부 확인

---

## 4. SSL / 인증서

- **HTTPS 적용**
  - [ ] 메인 도메인 및 서브도메인에 유효한 SSL 인증서 적용
  - [ ] 인증서 만료일, 자동 갱신(예: Let’s Encrypt) 설정 확인

- **구성**
  - [ ] HTTP → HTTPS 리다이렉트 설정
  - [ ] HSTS, TLS 버전 정책 등 보안 설정 점검

---

## 5. 애플리케이션 설정 (Next.js / 런타임)

- **빌드**
  - [ ] `npm run lint` / `npm run test` (있다면) 통과
  - [ ] `npm run build` 성공
  - [ ] 빌드 산출물(캐시, 이미지 등) 용량 및 배포 시간 점검

- **런타임**
  - [ ] 프로덕션 환경에서의 로그 레벨 설정 (debug 비활성화)
  - [ ] 헬스체크 엔드포인트 동작 확인
  - [ ] 서버/람다 타임아웃, 메모리/CPU 설정 확인

---

## 6. 관제 / 로깅 / 알림

- **모니터링**
  - [ ] 에러 트래킹(Sentry 등) 연동 및 테스트 이벤트 발생 확인
  - [ ] APM/로그 수집(예: CloudWatch, Datadog 등) 연결 확인
  - [ ] 핵심 지표(가입/전환/결제 등) 대시보드 정의

- **알림**
  - [ ] 장애 알림 채널(Slack, 이메일 등) 설정
  - [ ] 에러/응답시간/트래픽 임계치(Alert Rule) 정의

---

## 7. 보안 / 권한

- **접근 통제**
  - [ ] 관리자 페이지 IP 제한 또는 MFA 적용
  - [ ] 기본 관리자 계정 비밀번호 변경
  - [ ] 불필요한 테스트 계정/데이터 제거

- **기타 보안 항목**
  - [ ] CORS 허용 도메인 목록 점검
  - [ ] Rate Limit / 인증 실패 시 잠금 정책
  - [ ] 공개 저장소에 비밀정보 커밋 여부 점검

---

## 8. 롤백 / 배포 전략

- **롤백**
  - [ ] 이전 버전으로 되돌리기 전략 마련 (이미지 태그, 릴리스 태그 등)
  - [ ] DB 마이그레이션 롤백 시나리오 정의

- **배포 전략**
  - [ ] 배포 윈도우/점검 시간 공지
  - [ ] Blue-Green / Canary 등 점진적 배포 여부 검토

---

## 9. 최종 점검

- [ ] 스테이징 환경에서 주요 E2E 시나리오 모두 통과
- [ ] 이해관계자(기획/디자인/운영)의 최종 확인
- [ ] 배포 후 1~2시간 집중 모니터링 계획 수립
